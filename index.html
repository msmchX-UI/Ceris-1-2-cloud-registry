Quick Start

Pull an Image

docker pull registry.ceris.io/ceris/web-server:latest

Push an Image

docker tag myapp registry.ceris.io/<namespace>/myapp:1.0
docker push registry.ceris.io/<namespace>/myapp:1.0

Authenticate

docker login registry.ceris.io \
  --username <your-username> \
  --password <your-token>

About Ceris-1-2

Ceris-1-2 is an open, community-driven cloud registry built to handle the scale and security requirements of modern cloud-native workloads. Whether you are shipping container images, Helm charts, or language packages, Ceris-1-2 provides a single, trusted source of truth.

Our platform is built on open standards (OCI, ORAS, Sigstore) and designed to integrate seamlessly into existing developer workflows.
